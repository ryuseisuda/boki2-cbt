利用規約・免責事項

  • ベータ期間について: 本サイトは現在ベータ版として提供しており、2026年9月30日までのベータ期間中はすべての機能を無料でご利用いただけます。ベータ期間終了後の提供内容・機能構成・料金は変更される場合があり、模試など一部機能は正式版での有料化を予定しています。変更を行う場合は、事前に本サイト上でお知らせします。
  • 日本商工会議所・各地商工会議所・CBT試験運営会社(株式会社CBT-Solutions等)とは一切関係ありません。「日商簿記」は日本商工会議所の登録商標です。
  • 収録されている問題・解説はすべて運営者が作成したオリジナルであり、実際の検定試験問題の複製ではありません。

2. 免責事項

  • 掲載内容の正確性・完全性・最新性について、いかなる保証もいたしません。誤りを見つけた場合はご報告いただけると幸いです。
  • 本サイトの利用により生じたいかなる損害(検定試験の合否・学習結果を含む)についても、運営者は責任を負いません。
  • 本サイトは予告なく内容の変更・中断・終了を行うことがあります。
  • 試験の出題範囲・配点・方式は変更されることがあります。必ず日本商工会議所の公式サイトで最新情報を確認してください。

3. データの取扱い(プライバシー)

  • 未ログインの場合、学習記録(得点・正答率・連続日数・ペットの育成状態など)はお使いのブラウザ内(localStorage)にのみ保存されます。ブラウザの閲覧データを削除すると記録も消え、別の端末とは同期されません。
  • ログイン(任意)した場合、認証情報(メールアドレス、Googleログインの場合は氏名・プロフィール画像)と学習記録・ペットの育成状態が、認証と端末間同期のためデータベースサービス(Supabase)に保存されます。これらは同期・ランキング以外の目的には使用しません。
  • ランキングに参加(ニックネームを登録)した場合、次の情報が本サイトの全利用者に公開されます: ニックネーム、今週の問題数、連続日数、パターン制覇数、模試ベスト得点、ペットの名前・種類・育成状態。メールアドレスや氏名が公開されることはありません。ニックネームを空にすればランキングから非表示になります。
  • サイト改善のため、匿名の利用統計(画面の表示回数・模試の完了数など)を収集しています。Cookieや外部の解析サービスは使用せず、個人を特定できる情報は含まれません。広告は使用していません(ホスティングのGitHub Pagesが技術的なアクセスログを記録する場合があります)。

4. アカウントの削除

  • ログイン後、アカウント画面の「アカウントを削除(退会)」から、アカウント・クラウド上の学習記録・ランキング情報をいつでも完全に削除できます。
  • 削除がうまくいかない場合や、その他のデータ削除のご依頼は GitHub Issues からご連絡ください。

5. ゲーム機能(ペット・ごはん・ガチャ・ランキング)について

  • ごはん・ガチャ券・ペットなどのゲーム内要素はすべて無料で、金銭的価値はありません。
  • バランス調整・不具合対応のため、付与量・獲得条件・所持データを予告なく変更・調整・リセットする場合があります。
  • 不正な方法でランキングの数値を操作したと運営者が判断した場合、該当データの削除等の対応を行うことがあります。
  • 友だち招待の特典は、招待された方が新規にアカウント登録し10問正解した時点で双方に付与されます。自作自演や複数アカウントによる取得は禁止で、確認された場合は特典の取り消し等を行うことがあります。

6. 禁止事項

  • 問題・解説・その他コンテンツの無断転載、再配布、販売
  • 本サイトを自作と偽って公開する行為
  • 不正なデータの送信、ランキングの不正操作、その他本サイトの運営を妨害する行為
  • 公序良俗に反するニックネーム・ペット名の使用(運営者が変更・削除することがあります)

7. 著作権

  • 本サイトのコンテンツ(問題・解説・プログラム・画像素材)の著作権は運営者に帰属します。ドット絵素材の一部はAI生成ツール(PixelLab・Retro Diffusion)を利用して運営者が作成したものです。個人の学習目的での利用は自由です。

8. お問い合わせ

  • 誤りの報告・ご要望は GitHub Issues までお寄せください。
